# OpenAB

**OpenAB** is a lightweight, secure, cloud-native **ACP harness** — it connects chat platforms
(Discord, Slack, Telegram, LINE, Feishu/Lark, WeCom, Google Chat, Microsoft Teams) to AI coding
agents over the [Agent Client Protocol](https://agentclientprotocol.com/) via JSON-RPC. Message a
bot, and a coding CLI answers in the thread.

Written in Rust, OpenAB ships as Docker images with Kubernetes manifests and a Helm chart, so it
runs the same on a laptop or a cluster.

## Explore the docs

Use the sidebar or search (`/`) to browse platform setup, agent backends, features, deployment, and
the design records. Every page is also available as Markdown (append `.md`) and JSON, and via an MCP
tool at `/mcp` — one source, no drift.
